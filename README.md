# Adult Story Generator

A complete web app for generating uncensored adult stories in Hindi with AI images.

## How to Use

1. **Get API Key:**
   - Go to https://venice.ai
   - Create a free account
   - Get your API key from settings

2. **Open the App:**
   - Double-click `index.html` to open in browser
   - Or upload to any web hosting

3. **Generate Stories:**
   - Enter your API key
   - Select genre and language (Hindi/Hinglish/English)
   - Enter your story idea
   - Click "Generate Story"
   - Click "Generate Image" to create visuals

## Features

- ✅ Uncensored adult content
- ✅ Hindi, Hinglish, and English support
- ✅ Multiple genres (Romantic, Hardcore, BDSM, LGBTQ+, Fantasy)
- ✅ AI-generated images for scenes
- ✅ Adjustable intensity levels
- ✅ Works on mobile and desktop

## No Server Required!

This app runs entirely in your browser. Just open the HTML file and it works!
